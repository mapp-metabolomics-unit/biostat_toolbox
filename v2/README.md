# V2 environment

V2 is deliberately isolated from the root `renv` environment. The root environment pins the historical `MAPPstructToolbox` fork and R 4.2.2 so legacy analyses remain reproducible. V2 targets the official Bioconductor `structToolbox` package and does not load the fork.

Use R 4.6 to create the V2 environment:

```bash
cd v2
rig add 4.6
rig run -r 4.6 -f bootstrap.R
```

After bootstrapping, run V2 from its project directory so its own lockfile is activated:

```bash
# from v2/; keep using the explicit R version
rig run -r 4.6 -f run.R validate --dataset ../configs/mapp_batch_00275.dataset.yaml --recipe ../configs/mapp_batch_00275.recipe.yaml
```

The first snapshot generated by `bootstrap.R` should be committed as `v2/renv.lock`. Never replace the root lockfile with the V2 lockfile.
